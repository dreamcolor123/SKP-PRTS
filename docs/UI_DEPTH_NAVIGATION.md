# 遮挡同步、传感器轴向与精确导航

在 `codex/interaction-depth-navigation` 分支基于 `2e126d6` 继续修改，保留已确认的性能方案和所有旧 APK。

## 本轮行为

1. 档案正面的 DOM、深度遮罩、透视投影和三维画面使用同一呈现帧。异步 GPU 读取期间保留上一完整画面；准备完成后在同一次绘制回调里提交。切换新项目时标题和内容也延迟到该帧，快速连点会丢弃过期结果。瞬时读取失败保留当前完整画面并重试。
2. 保留真实三角形深度测试、可见对象筛选和异步读回。支持的 WebView 直接把深度栅格的可见区域合并为数值裁剪路径，避免逐帧 PNG 编码、解码和纹理上传；不支持时继续使用预解码图片回退。孔洞、前景遮挡和点击遮罩保持。
3. 用户最终确认的动作是竖屏握持后绕手机纵轴左右倾斜。原生姿态输入保留屏幕左右/上下语义；前端绕屏幕局部轴而非世界轴扰动。输入满量程由 12° 改为 10°，滤波由 160ms 改为 120ms，镜头最大微扰为约 3.09°/2.58°。旋转屏幕、后台恢复重新校准，减少动态归零。不接入平移加速度。
4. 卡面右上角改为单层折角档案 SVG，去掉叠纸效果的额外倾斜，保留真实卡面透视。按钮仍打开阵列浏览，透视后点击区在测试竖屏中大于 48px。
5. 工作区内部切换保持近景，相机主要小幅平移；新档案仍执行抽取和升起。只有阵列总览进入近景时保留原推进幅度，开场时间轴和镜头不变。
6. 阵列总览新增“上一张／下一张”，在当前栏位逐张循环，显示当前张数/真实总数。空栏和单张时禁用，底部五分区继续负责切栏；浏览其他栏时底部选中状态同步。360、412 和横屏保留至少 48px 点击区。

## 验证与限制

验证覆盖：延迟异步 GPU 完成、一次读取故障、快速连续切换、升起中的前景遮挡、帧号/投影/标题同步、相机轨迹、四种显示方向与多种初始握姿、同列精确步进/循环/空栏、毛玻璃、原模型保形及开场回归。

原生数学与浏览器轴向检查不能代替用户手机上的传感器体感；模拟器性能数字不作为真机结论。用户已确认上一版性能问题解决，本轮保留该事实，不重新把模拟器低帧率判成用户设备问题。完整命令、输出、APK、设备截图和回滚证据见事务 `VERIFICATION.txt`。Native/JNI/Root 协议未改。
