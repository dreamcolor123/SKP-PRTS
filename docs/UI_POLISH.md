# 遮挡性能、顶栏、视差、列序与音乐修复

本轮继续使用事务候选工程，保留 `refinement` 与更早 APK。原工程与 Native/Root 协议不变。

## 实现

1. 保留真实几何遮挡和 12px 卡面毛玻璃。遮罩先以保守投影包围盒剔除不相交、位于卡面后方的物体，再用原三角形执行 GPU 深度测试；实例只提交相关项。GPU 像素异步读回，遮罩 PNG 异步编码与预解码，同一时刻只有一个请求。换档、平面回退及销毁拒绝旧结果；失败时不可穿透点击并允许重新采样。归位对象的代理及时释放。控件阴影改为普通 box-shadow，避免每个按钮单独 filter 合成。
2. 右上角搜索、外观入口只保留参考符号，统一 48px 点击区和 24px 图标；保留读屏名称和悬停提示。弹窗置于顶栏上方，打开时顶栏隐藏且不可命中。
3. 镜头扰动由原幅度提高至六倍，上限约 2.06/1.72 度；控件附加偏移上限 1.8/1.5px，导航为 1.2px。继续使用校准、平滑、限幅与减少动态，不改变开场镜头。
4. 日常物理列和导航统一为概览、授权、模块、市场、设置，即 12345。稳定 ID、搜索条件、滚动位置不变。原开场仍抽取中间档案，交接后进入正确的概览列。
5. `presentation.audioActive` 与渲染 `active` 分离。原生面板可冻结背景但不断开 BGM；Web 设置/搜索不暂停音乐。真正进入后台仍暂停，恢复继续；首次 Root 配置表单不提前播放。
6. 加高只延展玻璃壳体、边框和背板。内部光学结构统一居中刚性平移；圆点、标签、刻度按顶部/底部锚点平移，保持原尺寸和边距。混合材质按焊接连通部件分组，法线同步补偿；额外字标贴图与实体标签共同顶部锚定。几何仅在高度变化时上传，同一份几何供选中、阵列、归位卡及 GPU 遮挡使用，不增加绘制批次。开场恢复原几何。

## 已执行验证

- 真实 GPU 遮罩与独立全场景深度基准逐字节一致；DPR 1/2、前后遮挡、屏外对象、201 实例、倾斜和开孔几何均覆盖。201 实例场景仅保留 1 个相交实例。
- 浏览器五分区、透视、前景遮挡、毛玻璃实际像素、大字体、横竖屏、导航、平面回退和操作请求验证通过。模拟方向输入角点位移约 2.33px，之前约 0.40px；不是物理手机传感器手感测试。
- 4 个视口的顶栏图标尺寸、弹窗层级及点击隔离通过。
- Web 搜索/设置、原生面板、后台/恢复音频时钟与播放轨道验证通过。
- 开场 16 组截图的几何一致，2627 个运动参数采样零差异；品牌和业务文本不主张逐像素一致。

桌面同场景诊断中，旧遮罩同步 GPU 读回累计约 519ms，单次最高 15.6ms；优化后读回异步提交累计约 0.9ms，交互路径同步读回和 `toDataURL` 次数均为 0。稳定页遮罩提交 5 个相关对象、3378 个三角形。两版本桌面帧间隔均约 16.7ms，因此不把这些数据表述为真机帧率提升。关闭毛玻璃的对照未发现明显桌面帧率差异，故保留原毛玻璃参数。

最终 APK 摘要、Android 定向测试、构建及回滚结果见事务 `VERIFICATION.txt` 和交付目录的测试说明。之前模拟器完整套件发生系统进程崩溃中止，原失败证据保留；不能据此声称完整 Android 矩阵通过。真机 Root、传感器体感、高刷、GPU 驱动与温升仍需实机测试。
