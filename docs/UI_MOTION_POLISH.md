# 一秒清晰与连续开场镜头

本页覆盖最新追加的动画调整，早期“原镜头逐帧不变”结论仅对应历史版本。

## 日常抽取

`INTERACTIVE_CLEAR_DURATION=1`。开始抽取即启动磨砂转清晰，不再等待镜头缩近或高度阈值。材质按平滑曲线在半秒达到约 50%、一秒达到完整清晰；再次进入从当前清晰度继续。模型、DOM 遮挡与颜色仍成对呈现。

动画使用实际活动时间，5/30/60/120Hz 下均在一秒完成；进入后台停止推进，恢复不累计隐藏时间。减少动态直接到终态。完整开场里的解密/玻璃参考时间轴保持原值，日常动画速度与其分离。

## 开场镜头

新增 `cinematicCameraPose()`，把绕行、抬头、推近、瞄准和屏幕锚点合并为共享切线的连续 Hermite 轨道。消除 25.05/27.3 秒分支切换时的位置重置，放缓原 0.22 秒急抬头；内部结点保持位置和速度连续，不再每段分别 ease 到零。

只调整三维相机轨迹。MG、Logo、阵列波浪、抽取模型和整体开场结束时间不改；工作区之间的小幅平移与传感器视差继续独立运行。该新轨迹按用户要求有意偏离原参考镜头，不声明与旧镜头逐像素相同。

测试覆盖 16 个结点 C0/C1、手机/桌面各 787 帧、关键分段和实际 35 秒交接。日常玻璃真实浏览器记录约 994ms 达到清晰，约 512ms 清晰度为 0.532；暂停/恢复检查通过。最终 APK 和执行输出见事务验证文件。
