# 用户新版 Logo 接入

以用户提供的 `skroot-pro-preview.html` 为标识与动画的唯一设计源，原文件不修改；候选工程保存逐字节相同的来源副本和摘要。

## 替换范围

- Web 开场原 Logo：改为紫色连体 SK，保留原四条路径、渐变及 1.3 秒拼合、4.2 秒高光循环。原描边、终端符号和局部擦除时序不再驱动 Logo。
- Welcome 与加载入口：使用同源标识和运动，多个 SVG 使用独立 ID，不串用渐变或裁剪。
- 模型标签、favicon、Web 安装图标、Android 桌面图标：使用相同标识，保持原比例和图标安全区；应用图标与自适应背景统一为 `#11181B`，与暗色界面同色。
- Android 系统启动：同源渐变 VectorDrawable 与 1300ms 单次入场动画；系统可能按自身启动时长提前结束，循环高光由应用内负责。静态启动回退显示完整标识。

原有 SKRoot Pro 字标、其余开场 MG、三维镜头、业务数据和交互不改。新 Logo 不拉伸，模型贴标按路径实际宽高比绘制。减少动态时显示完整静态标识，后台或原生遮挡暂停，恢复后不累计隐藏时间。

## 验证

独立浏览器测试直接运行来源 HTML，在固定时钟下比较 9 个时间点的路径、渐变、透明度、位移、bridge 擦入与高光坐标，并比较同尺寸像素。覆盖多实例引用、静态和减少动态。另验证真实宿主暂停/恢复、手机/桌面画面、APK 构建与启动。

本次仅替换 UI 品牌资产和动画；Native/JNI/Root 协议、包名、版本及 SDK 边界不变。不配置远端或正式签名。最终执行结果与未测项以事务 `VERIFICATION.txt` 为准。
